# Release 0.2.1

- Catalyst 6.7 and 8.12: successful Windows XP hardware tests reported by the project owner, test date 2026-10-11.
- Internal layout-family identifiers use the earliest supplied version: 5.12 and 8.6 replace names based on 6.7 and 8.12. Exact variants retain identifying suffixes.
- The console reports "Supported function layout found." instead of an internal pattern name and file offset.
- Previous vendor-specific option references were removed. Recognition of previously modified files remains for input rejection.
- Patch instructions and output driver bytes are unchanged.
